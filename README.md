# LabLine

A real-time queue for college lab assistance and doubt-solving.

## Problem

Students often wait for help during lab sessions without knowing their
position in the queue or when a mentor will be available.

LabLine aims to make help requests, queue management, and mentor availability
visible through one shared application.

## Core Workflows

- Students submit and track help requests.
- Students see their queue position and estimated waiting time.
- Mentors claim requests and update their status.
- Queue changes appear in real time.
- Mentors view basic queue and resolution statistics.

## Planned Technology Stack

- React
- Tailwind CSS
- Node.js and Express
- MongoDB
- Socket.IO

## Project Status

Initial setup. Core workflows and architecture are to be implemented.

## Development Principles

- Build a small number of complete, reliable workflows.
- Validate inputs and enforce authorization on the server.
- Keep credentials and secrets out of source control.
- Test important success and failure cases.
